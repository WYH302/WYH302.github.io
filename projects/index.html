Guangzhou Transportation Bureau commissioned project | Core technical contributor | 2024-2025

Urban Infrastructure Hazard Perception, GPR Defect Analysis, and Bridge Anti-Collision Multi-Modal Visualization Platform

Contributed as a core technical contributor to an end-to-end infrastructure perception pipeline covering road-hazard detection, GPR-based crack and pothole recognition, sample curation, detection-model training, and object-imaging preprocessing. Delivered a unified multi-modal visualization interface integrating live video, radar signals, automated alarms, and model inference views; the work led to three related invention-patent outputs.

Contribution
Dataset/sample curation, detection-model training, object-imaging preprocessing, and multi-modal interface integration.
Visible output
Road-hazard perception workflow, GPR defect analysis pipeline, alarm views, and patent-linked technical modules.
Evidence type
Commissioned project context with three related invention-patent outputs: CN120045978A, CN118918519B, and CN118604817B.

Self-Initiated Research and Engineering Project

StoneVL-Nest / CF-SlabNest: Vision-Language-Driven Verifiable Industrial Nesting Compilation System

Architected a multimodal compilation pipeline translating Chinese natural-language cutting orders and visual defect constraints into geometrically verified stone-cutting nesting layouts. Formalized the core task as a maximum-count irregular nesting problem and designed independent geometric feasibility verification with auditable certificate output.

Contribution
Problem formalization, multimodal parsing design, irregular nesting constraints, and independent geometry verification.
Visible output
Prototype compilation path from Chinese cutting orders and defect constraints to auditable nesting-layout certificates.
Research value
Connects vision-language grounding with verifiable industrial optimization rather than relying only on generated layouts.
vision-language systems industrial nesting geometric verification auditable output

Self-Initiated Research and Engineering Project

Multi-Agent Social Simulation and LLM-Orchestrated Agentic Workflow Prototype System

Constructed a full-stack multi-agent social simulation with React, Phaser, and Node.js, supporting persistent character memory, structured dialogue scheduling, and longitudinal relationship evolution. Co-designed a deterministic Agentic Web prototype with event-driven state persistence and closed-loop decision, feedback, and resource tracing to validate LLM-orchestrated workflow automation under operational constraints.

Contribution
Full-stack prototype construction, memory/state modeling, dialogue scheduling, and deterministic workflow tracing.
Visible output
React/Phaser/Node.js simulation interface and Agentic Web prototype with event-driven state persistence.
Research value
Used as a controlled environment for studying lightweight agent social dynamics and workflow automation failure points.
multi-agent systems React Phaser LLM workflows
