Multimodal agents for computational imaging

Can an agent use a measurement to decide what to measure next, or whether to reconstruct the image again? I want to test this in computational imaging. The work is still a proposal, not a validated system.

Motivation

In computational imaging, a reconstruction depends on how the data was measured. A downstream model then uses that reconstruction to recognize objects or make another prediction. An error early in the process can affect every later step. An agent could help choose the next operation, but it would need access to the measurements and their limits, not just the final image.

Research questions

The first difficulty is representing optical measurements, sparse observations, and reconstructed images in a form the agent can compare. It would also need to use simulators, reconstruction modules, segmentation models, and evaluation scripts without treating uncertain outputs as established facts.

I would test the decision to collect more data separately from the decision to change the reconstruction method. Sometimes neither will justify a confident prediction; the system needs to be able to defer an answer.

Possible direction

The agent could select a measurement, pass it to a reconstruction module, and compare the result with the task requirements before choosing another tool. Each call would retain its inputs and outputs. Physics and signal-processing models would still perform their own calculations; the agent would coordinate them and explain why it chose a particular step.

Practical caution

A plausible measurement suggestion may still waste time or collect no useful information. The prototype should keep the inputs, reconstructions, and uncertainty estimates so that a reviewer can separate evidence from the agent's guesses. I would compare it with a fixed imaging pipeline: does it improve reconstruction quality for the same measurement cost, or reach the same quality with fewer measurements?
